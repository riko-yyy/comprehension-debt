# 0013: リポジトリを公開し、理解の記録は手元だけに置く

- 日付: 2026-10-16
- ステータス: 提案

## 背景

Phase 6 では、レポートを毎日自動で更新し、GitHub Pages で見られるようにする。
このリポジトリは非公開だったが、GitHub Pages は無料プランでは公開リポジトリからしか使えない。
また vision.md では、このプロジェクトの位置づけを「ポートフォリオ」としている。

公開前に、全履歴（29コミット、32ファイル）を確認した。API キー・トークン・秘密鍵・パスワード・手元の絶対パス・個人のメールアドレスは見つからなかった。

## 決定

- リポジトリを公開し、Phase 6 のレポートは GitHub Pages で公開する
- 次のものは、公開前に今のファイルから消す
  - claude.ai のアーティファクトへのリンク（vision.md）。本人にしか開けず、他の人には意味がない
  - `docs/understanding-log.md`（クイズで答えられなかった点の記録）。git の管理から外し、`.gitignore` に入れて手元にだけ置く
- 過去の履歴は書き換えない。コミットメッセージにある claude.ai のセッションへのリンクと、過去のコミットに含まれる `understanding-log.md` は履歴に残る
- `Co-Authored-By: Claude` などの trailer は消さない。このツールがコミットの由来（自律／併走／人間）を判定するための、元のデータそのものだから

## 検討した選択肢

- 公開用のリポジトリを別に作り、レポートだけを出す — 仕組みが複雑になる。ポートフォリオとしては、ツールと記録をまとめて見せたい
- Pages を使わず、Actions の成果物（ZIP）にする — 見るたびにダウンロードが必要で、毎日眺めるのに向かない
- 履歴を書き換えて完全に消し、新しい公開リポジトリに移す — PR #1〜#8 の記録が引き継げない。残るものはどれも、他人に開けないリンクと理解の穴だけで、実害が小さい

## 結果

Pages が無料で使え、ADR や計画を含めてそのまま見せられる。
理解の記録は手元にしかないので、別の PC で作業するときは引き継がれない。
履歴をたどれば、消したものも見える。
