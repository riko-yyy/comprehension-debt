# 0005: 段階1は自分用の中央バッチに絞る

- 日付: 2026-09-25
- ステータス: 採用

## 背景

理解スコアが本当に使える指標かどうかは、まだ分からない。
GitHub Action 化・GitHub App 化・仕様ドリフト検知・一問レビュー bot など、広げ方はいくつも考えられる。

## 決定

段階1は「自分のリポジトリを対象に、ファイル／ディレクトリ単位の理解スコアと危険地帯が、
静的ページで毎日自動更新される」ところまでに絞る。
上記の拡張は、段階1のスコアを実際に眺めて「使える指標だ」と確かめてから着手する。

最初の分析対象は `design-doc-repo`（AI コミットが実際に溜まっているため）。

## 検討した選択肢

- 最初から Action / App として作る — 指標が使えるか分からないうちに配布の仕組みへ投資することになる

## 結果

作るものが小さく保てる。一方で、他人のリポジトリでの使い勝手は段階2まで検証できない。
