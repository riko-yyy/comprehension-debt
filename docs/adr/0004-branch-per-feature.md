# 0004: 機能単位でブランチを切る

- 日付: 2026-09-25
- ステータス: 採用

## 背景

Phase 0 のコミットを最初は main に直接積んでいた。
Phase は作業の区切りだが、Phase 0（CLI の骨組み）だけでは単体で意味のある機能にならない。

## 決定

main には直接コミットしない。機能単位でブランチを切り、完成したら main に取り込む。
ブランチは Phase と1対1にはせず、意味のあるまとまりで切る。

- `phase-0-1-git-history` — Phase 0（CLI の骨組み）と Phase 1（git 履歴の読み取り）

## 検討した選択肢

- Phase ごとに1ブランチ — Phase 0 が小さすぎて、単独では取り込む価値がない
- 段階1全体で1ブランチ — 1〜1.5か月分が1本になり、main が長く空のままになる

## 結果

main は常に「動く状態」を保てる。
ブランチ名に Phase 番号を含めるので、計画との対応が分かる。
