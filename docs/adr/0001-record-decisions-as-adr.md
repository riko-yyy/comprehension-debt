# 0001: 意思決定を ADR として記録する

- 日付: 2026-09-25
- ステータス: 採用

## 背景

このプロジェクトは週末ペースで1〜1.5か月かけて進める。間が空くと「なぜこうしたか」を忘れる。
また AI と一緒に作業するため、会話の中で決めたことがリポジトリに残らないと、後から追えない。
理解負債を測るツール自体が理解負債を抱えるのは避けたい。

## 決定

設計・技術選定・進め方に関わる意思決定は `docs/adr/NNNN-タイトル.md` に1件1ファイルで記録する。
書式は `0000-template.md` に従う。番号は連番で、一度書いた ADR は書き換えず、覆すときは新しい ADR で置き換える。

## 検討した選択肢

- README に書く — 決定が増えると埋もれる。経緯（なぜ）を残しにくい
- 記録しない — 上記の理由で却下

## 結果

決定のたびに少し手間が増える。代わりに、Phase を再開するときや λ などを見直すときに根拠をたどれる。
