# 理解の記録

フェーズの終わりに出したクイズで、答えられなかった点を残す（CLAUDE.md）。このツール自身の理解負債の記録。

## 2026-10-16 Phase 2・4

| 問い | 答え | 押さえたいこと |
|---|---|---|
| AI が新しく作ったファイルのスコアの初期値と、なぜ 0 でないか | 0.5（併走を想定） | 併走は `exp(-0.5)=0.61`、自律は `exp(-1)=0.37`。理解度は 1（まだ理解すべきものがない）から始まり、作成という変更（割合 1）で1回だけ下がるので 0 にはならない。併走の値の感覚は合っていた |
| スコア 0.4 のファイルを人間が1行直すと | 分からない | 戻るのは「理解していなかった分 × 変更の割合」。100行なら `0.4 + 0.6 × 0.01 = 0.406` でほぼ動かない。1行で満点に戻るごまかしを防ぐ（ADR 0007） |
| ack の翌日に AI がファイルの半分を書き換えると | 0.75 くらい | 書き換えは削除 + 追加で2倍に数えるので、半分の書き換えは割合 1 になり、新規作成と同じだけ下がる（併走 0.61、自律 0.37）。直感より強く下がる（ADR 0007 の注意点） |
| スコア 0.1 なのに危険地帯に出ない理由 | 除外されている | 除外されたファイルはスコア自体が出ない。答えは「直近90日に変更がない（変更頻度 0 → 危険度 0）」か「core 以外で重要度 0.3」（ADR 0011） |

答えられたこと: ack で 1 に戻る。自律のコミットがないので λ と併走倍率は積でしか効かない。
