# 段階1 計画

## ゴール

自分のリポジトリを対象に、ファイル／ディレクトリ単位の理解スコアと「危険地帯」が、
静的ページで毎日自動更新されて見られる状態。（範囲の決定: ADR 0005）

## フェーズ

| Phase | 内容 | 完了条件 | 状態 |
|---|---|---|---|
| 0 | CLI の骨組み（TypeScript + tsx） | `score <path>` で受け取ったパスが表示される | 完了 |
| 1 | git 履歴の読み取りと由来の判定（自律／併走／人間） | ファイルごとに由来別の変更行数が表で出る | 完了 |
| 2 | 理解スコア計算（簡易版） | スコアの低い順にファイルが並び、自分で納得できる | 完了 |
| 3 | 実質レビューを理解イベントに加える | レビュー済みファイルのスコアが回復する | 後回し |
| 4 | 重要パスと危険地帯 | ターミナルに危険地帯トップ10が出る | 完了 |
| 5 | 可視化（ツリーマップの静的 HTML） | ローカルで色分けされたツリーマップが見える | 完了 |
| 6 | 中央バッチ化（scheduled workflow） | 毎朝ページが自動で更新される | |

## 各フェーズのメモ

### Phase 1
- `git log --no-merges --numstat` を使う。マージコミットを含めると行数が二重に数えられる
- AI 判定と行数の数え方は ADR 0006
- `Co-authored-by` は `--format` の `%(trailers:key=Co-authored-by,valueonly)` で取り出す
- パース時の注意: リネームは `{old => new}`、バイナリファイルは行数が `-`
- squash merge 時の author が人間になっていないか、対象リポジトリで確認する

### Phase 2
- λ=1、併走倍率=0.5 は暫定の既定値（ADR 0011）。Phase 6 の後、使いながら見直す
- 計算方法は ADR 0007（履歴を再生し、変更の割合で上げ下げする）。1行の修正で満点に戻る問題を避けた
- `npm run cli -- score <path> --lambda 1 --pair 0.5`。Phase 1 の表は `lines` サブコマンドに移した
- 併走しかないリポジトリでは、λ と併走倍率は並び順に効かない。値の確定は Phase 4 で閾値と一緒に行う

### Phase 3
- 後回しにする。手元のリポジトリ（design-doc-repo など5つ）には人間の PR レビューが1件もなく、作ってもスコアが変わらない。代わりに一人開発向けの `ack`（自己申告の理解イベント、ADR 0009）を作った。Phase 4〜6 に進む
- `gh api` で PR のレビューとコメントを取得し、コメントや修正要求を伴うレビューを理解イベントにする

### Phase 4
- 除外ルールと `understanding.yml` の読み込みは ADR 0008 で実装済み。`core:` は同じファイルに足す
- `understanding.yml` の `core:` で重要パスを宣言する
- 危険地帯 = 重要度高 × スコア低 × 変更頻度高。式と重要度の決め方は ADR 0011。`npm run cli -- danger <path>`

### Phase 5
- `npm run cli -- report <path>` で `out/report.json` と `out/index.html`。形と見せ方は ADR 0012
- ファイル数が500を超えたら、ディレクトリのズームを足す（ADR 0012）
- JSON には、理解するための材料（最後に理解した日時と、それ以降の変更）も含める（ADR 0013）
- 結果を JSON に出力し、D3 などを CDN から読み込んでツリーマップを描く

### Phase 6
- `actions/checkout` は既定で最新1コミットしか取得しない。必ず `fetch-depth: 0`（全履歴）にする。行数を履歴の積み上げで推定しているため（ADR 0007）、履歴が欠けると行数もスコアも黙ってずれる
- 対象リポジトリを clone して分析し、結果を公開する。private を対象にするなら読み取り用トークンを Secrets に登録
- 注意: private リポジトリの Pages 公開は有料プランが必要。公開ページには対象リポジトリのファイルパスと「理解できていない場所」が載る。公開先はここで決める（決めたら ADR）
